# Logos

The Original Lumia logo — the only palette Lumia uses. Full logos are 1254 × 1254 viewBox (PNG 2048 × 2048) with built-in clear space; the icon is 640 × 640 (PNG 1024 × 1024). All share one alignment, so light and dark swap in place.

- `lumia-original-light.svg` / `.png` — Transparent; ink wordmark (#0B0B20). Use on light grounds (`bg`, `surface`, white).
- `lumia-original-light-on-white.svg` / `.png` — The same on a solid #FFFFFF ground, for places that can't take transparency.
- `lumia-original-dark.svg` / `.png` — Transparent; near-white wordmark (#F7F8FD). Use on dark grounds only — on white the lettering disappears.
- `lumia-original-dark-on-dark.svg` / `.png` — The same on a solid #0F1220 ground.
- `lumia-original-icon.svg` / `.png` — The two-bubble symbol alone; identical in both themes. Home tile, app icon, favicon.

The colours are fixed gradients (the `brand-*` tokens are their stops); there is no single-ink version, so never recolour the files.
