# Icons

The 30 stroke icons used across Lumia, 26 lifted from the product design and four drawn after it for the device list and the encryption notice (`globe`, `monitor`, `phone`, `shield`): 24 × 24 grid, round caps and joins, stroke 1.8–2.2 (lock 2.6; `more` is three filled dots). These files are drawn in #4C525E (`ink-quiet`, light theme) so they show as pictures; in code use the `Icon` component, which draws the same paths in `currentColor`.

- Navigation: `hash`, `lock`, `chevron-down`, `search`, `compose`, `plus`, `thread`, `mention`, `saved`
- Conversation: `voice`, `pin`, `more`, `reaction-add`, `emoji`, `send`, `file`, `download`, `member-joined`
- Reactions: `thumbs-up`, `check-circle`, `heart`, `sparkle`
- Sign-in: `eye`, `eye-off`, `key`, `mail`
- Devices and encryption: `globe`, `monitor`, `phone`, `shield`
