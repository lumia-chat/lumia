# Icons

The 37 stroke icons used across Lumia, 32 lifted from the product design (`back` from the iOS boards) and five drawn after it: four for the device list and the encryption notice (`globe`, `monitor`, `phone`, `shield`) and `members` for the button that shows a narrow window its side panel: 24 × 24 grid, round caps and joins, stroke 1.8–2.2 (lock 2.6; `more` is three filled dots). These files are drawn in #4C525E (`ink-quiet`, light theme) so they show as pictures; in code use the `Icon` component, which draws the same paths in `currentColor`.

- Navigation: `hash`, `lock`, `chevron-down`, `back`, `search`, `compose`, `plus`, `thread`, `mention`, `saved`, `members`
- Conversation: `voice`, `pin`, `more`, `reaction-add`, `emoji`, `send`, `file`, `download`, `member-joined`
- Reactions: `thumbs-up`, `check-circle`, `heart`, `sparkle`
- Sign-in: `eye`, `eye-off`, `key`, `mail`
- Menus and cards: `user`, `preferences`, `sign-out`, `check`, `close` (the account menu and the profile card)
- Devices and encryption: `globe`, `monitor`, `phone`, `shield`
