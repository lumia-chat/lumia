# Icons

The 38 stroke icons used across Lumia, 32 lifted from the product design (`back` from the iOS boards) and six drawn after it: four for the device list and the encryption notice (`globe`, `monitor`, `phone`, `shield`), `members` for the button that shows a narrow window its side panel, and `settings`, the gear of a server's settings (the boards draw none): 24 × 24 grid, round caps and joins, stroke 1.8–2.2 (lock 2.6; `more` is three filled dots). These files are drawn in #4C525E (`ink-quiet`, light theme) so they show as pictures; in code use the `Icon` component, which draws the same paths in `currentColor`.

- Navigation: `hash`, `lock`, `chevron-down`, `back`, `search`, `compose`, `plus`, `thread`, `mention`, `saved`, `members`
- Conversation: `voice`, `pin`, `more`, `reaction-add`, `emoji`, `send`, `file`, `download`, `member-joined`
- Reactions: `thumbs-up`, `check-circle`, `heart`, `sparkle`
- Sign-in: `eye`, `eye-off`, `key`, `mail`
- Menus and cards: `user`, `preferences`, `settings`, `sign-out`, `check`, `close` (the account menu, the menu under a server's name and the profile card)

`sign-out` is not as the boards draw it. Theirs is an arrow going into a door, the picture every icon set calls log-in; this one is the same door mirrored with the arrow leaving (2026-11-12). The boards on the design canvas still carry the old one.
- Devices and encryption: `globe`, `monitor`, `phone`, `shield`
