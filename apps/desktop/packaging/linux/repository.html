Lumia for Linux

Lumia @VERSION@, a preview: it has been built and tested without a screen, and nobody has used it on a Linux desktop yet. Please say what you find.

Debian and Ubuntu

On an Intel or AMD computer (x86-64):

curl -fLO @URL@/apt/pool/main/lumia_@VERSION@_amd64.deb
sudo apt install ./lumia_@VERSION@_amd64.deb

On an Arm computer (arm64):

curl -fLO @URL@/apt/pool/main/lumia_@VERSION@_arm64.deb
sudo apt install ./lumia_@VERSION@_arm64.deb

The package adds this repository to apt as it installs, so Lumia updates with the rest of the system.

Fedora and other dnf systems

On an Intel or AMD computer (x86-64):

sudo dnf install @URL@/rpm/x86_64/lumia-@VERSION@-1.x86_64.rpm

On an Arm computer (aarch64):

sudo dnf install @URL@/rpm/aarch64/lumia-@VERSION@-1.aarch64.rpm

The package adds this repository to dnf; the first update asks you to accept its key.

Anywhere else

The AppImage from the latest release runs on its own and updates itself. Make it executable and open it; it needs FUSE, which most desktops have.
